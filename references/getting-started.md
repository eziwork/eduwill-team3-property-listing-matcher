# 시작·등록 안내

## 언제 보여줄지

- 첫 사용·도움말·매물장 등록 여부·활성 매물장 질문 또는 활성 프로필이 없을 때 짧게 안내한다.
- 등록 방법을 묻고 실제 매물 정보는 아직 주지 않았을 때 등록 안내를 덧붙인다.
- 활성 프로필이 있고 구체적인 작업을 요청했거나 이미 매물 정보를 줬다면 소개·예시를 반복하지 않는다.

현황 질문은 읽기 전용으로 답한다. 새 매물장 생성·연결·전환을 임의로 수행하지 않는다.

## 현황 확인

1. 이 환경에서 처음 실행한다면 `environment-setup.md`의 환경 확인을 먼저 통과한다.
2. `profile list`로 저장된 연결 프로필 수와 활성 이름을 확인한다.
3. 활성이 있으면 `profile show`로 저장 방식과 원본 링크 또는 절대경로를 확인한다.
4. 로컬 검증 실패는 “프로필은 있으나 연결이 끊김”으로 설명하고 새 파일을 만들지 않는다.
5. Google은 저장 정보만으로 정상 연결이라 단정하지 않는다. 실제 작업이나 연결 검증 요청이면 Google 연결 게이트를 실행한다.

프로필 수는 실제 사용 가능한 원본 수나 매물 건수가 아니다. 매물 건수는 원본을 읽어 집계한 경우에만 말한다.

## 짧은 시작 안내

Google Sheets나 로컬 Excel을 운영 원본으로 연결해 매물을 등록·변경하고 손님 조건으로 찾는 기능이라고 한 문장으로 설명한다.
이어 현재 연결 프로필 수와 활성 매물장의 이름·방식·링크 또는 경로를 보여준다. 프로필이 없으면 없다고 말하고 두 저장 방식 중
하나를 고르게 한다. 상황에 맞는 다음 행동 예시 하나만 제시한다.

## 등록 방법 안내

먼저 현재 저장 대상의 **이름·저장 방식·링크 또는 절대경로**를 보여준다. 그다음 아래 뜻만 간단히 전달한다.

> 정보를 자세히 주실수록 정확하게 정리할 수 있지만, 정해진 양식을 맞출 필요는 없습니다. 알고 있는 내용을 편하게 적어주세요.
> 예: `구로구 오류동 아파트, 전세 2억 8천, 84㎡, 즉시 입주`

원하면 `종류 / 거래 / 지역 / 가격 / 단지·동호 / 면적 / 입주 / 특징` 목록을 보여줄 수 있으나 필수 양식이라고 말하지 않는다.
이미 정보를 받았다면 이 안내를 반복하지 말고 실제 값만 정리해 활성 원본과 함께 저장 전 확인을 받는다. 빠진 값은 만들지 않고,
종류·거래·지역이 불명확하면 보류 가능성을 알린다.

내부 명령, 프로필 저장소 경로, JSON은 요청받지 않는 한 보여주지 않는다.
